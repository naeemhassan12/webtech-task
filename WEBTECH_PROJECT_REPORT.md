# WebTech Task Management System - Project Report

## 1. Project Overview
The WebTech Task Management System is a robust Laravel-based web application designed for managing team tasks with role-based access control (RBAC). It features real-time sidebar updates, AJAX-powered task creation, and a professional user interface.

## 2. Key Features
- **User Authentication**: Secure login, registration, and password management (Laravel Breeze).
- **Role-Based Access Control**:
  - **Superadmins/Admins**: Can view, create, edit, and delete all tasks. They can also manage members assigned to tasks.
  - **Users**: Can only view tasks they are specifically assigned to.
- **Task Management**:
  - CRUD operations for tasks.
  - Status tracking (Pending vs. Active).
  - Member assignment to specific tasks.
- **Dynamic Interface**:
  - AJAX-based task store/update for a seamless experience.
  - Real-time sidebar updates using polling/AJAX to show current pending and active tasks.
- **Professional Aesthetics**: Custom CSS for a modern Look & Feel.

## 3. Technology Stack
- **Backend**: Laravel 12.0
- **Frontend**: Blade Templates, Vanilla CSS, JavaScript (AJAX/Fetch)
- **Database**: MySQL/MariaDB (via Eloquent ORM)
- **Authentication**: Laravel Breeze
- **Testing**: PHPUnit / Laravel Feature Testing

## 4. Database Schema
- **users**: ID, Name, Email, Password, Role (admin, superadmin, user), Timestamps.
- **tasks**: ID, Task Title, Client Name, Description, Status (0=Pending, 1=Active), Timestamps.
- **task_user**: Pivot table linking users and tasks (user_id, task_id).
